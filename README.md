# Your AI OOTD Wardrobe

Can't decide what to weaar for the day? No worries! Let AI do the job for you.

## Quickstart
1. Open the [website](https://lizonair.github.io/Ai_OOTD/)

2. Simply drag and drop an image of your clothes into each categories.

3. Go to the OUTFITS tab.

4. Select the occasion that you like.

5. Generate outfits.

TADA Now you have a bunch of ideas for your OOTD!

## Description
This app prioritize users' privacy. It stores users' data on local storage instead of server, this means that the datas of user are stores locally on their devices, no data leakage. Moreover, the AI model is CDN hosted, runs locally on user's browser without API request. So there's no need to worry about data or privacy used to train models or exposed to the public.
